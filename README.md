# KlemantanImmersive.id

Platform edukasi imersif warisan budaya Kalimantan Timur. Pengguna dapat menjelajahi ruang 3D, menonton video 360°, membaca kisah budaya, dan mengoleksi kartu karakter.

**Website:** https://budayaetam.github.io/KlemantanImmersive.id/

## Isi

- **Budaya:** Hudoq (Suku Dayak Modang), Sangkulirang-Mangkalihat (cagar budaya), serta bacaan Erau, Sandima, Belian Paser Nondoi, Masjid Shiratal Mustaqiem, dan Prasasti Yupa.
- **Jelajah 3D:** Hutan Hudoq, Ceruk Tewet, Ceruk Karim.
- **Video 360°:** Hudoq, Karst Sangkulirang-Mangkalihat, Maestro Hudoq.
- **Koleksi Kartu:** 11 karakter Hudoq.

## Teknologi

HTML, CSS, dan JavaScript dalam satu halaman statis. Ruang 3D memakai three.js. Website ditayangkan melalui GitHub Pages.
